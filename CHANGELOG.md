# Changelog

All notable changes to G3MLib are documented in this file.

## [1.0.0] - 2026-09-06

### Added

- Initial standalone release for reading, writing, analyzing, compiling, and decompiling GameMaker data files.
- Game-specific definitions and analyzer data for supported GameMaker games.

### Changed

- Consolidated and modernized the data-file, compiler, decompiler, and project serialization APIs for .NET 10.
- Renamed the `G3MLib.Data` namespaces to `G3MLib.DataFile`.
